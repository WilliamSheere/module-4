# module-4

Personal Blog with Dynamic Content & Dark Mode Toggle

Project Overview
This project is a simple personal blog built with HTML, CSS, and JavaScript. The goal is to build a content form, dynamically render blog posts, and implement a light/dark mode toggle. This will provide hands-on experience with JavaScript's DOM manipulation and help set the foundation for more advanced web development tasks.

Features
Content Form: Allows users to submit a blog post.
Dynamic Post Rendering: Blog posts are displayed dynamically on the page.
Light/Dark Mode Toggle: Users can switch between light and dark modes for a personalized viewing experience.

Technologies Used
HTML for the structure of the page.
CSS for styling and layout.
JavaScript for handling form submissions, dynamic content rendering, and the light/dark mode toggle.
